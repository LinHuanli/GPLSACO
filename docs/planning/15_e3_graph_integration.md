# E3实际图匹配、固定槽位与约束接入

本开发协议承接真实LKH导出发现的度数差异，不依据正式测试性能修改先验。E3仍需Hard/Escape完整集成、独立训练和配对实验；本文件不宣称实验已完成。

## 实际图与共同初始化

共同初始tour由现有无标签CPU准备流程产生：相同坐标、NN初始解、相同真实近邻LS与其计数上限。四条件均使用该tour，禁止候选工具提供更优初始化。提供给Engine的初始tour必须与此流程逐节点一致；不得只核验成本接近。

逐节点取原生先验前16个成员（不足则取全部），将其无向化。令H为共同初始tour的n条无向边；先验可供增加的集合为候选并集去掉H。alpha和POPMUSIC共同使用两集合大小的较小值B，各自保留恰好B条额外边，因此E0均有n+B条边，且包含H。边的优先级为两方向中较小的原生行排名，再按较大的排名、端点ID破平局；缺失方向视作无限排名。不使用标签或整数Alpha值的跨节点尺度来打破平局。

该规则匹配实际无向边数，不声称节点度数序列相同。记录完整度数分布和两先验各自删去的边数。全图用于合法性检查，不因转移行或LS行宽而截断图。边上限为n×(primary_width+1)，只用于预分配；若显式输入超过上限则拒绝，绝不静默裁剪。

## 三个独立视图

- 主转移行：E0的所有邻接成员按原生行排名、节点ID排序，选前16；共同tour边无原生排名时排在有排名边之后。不足位置以哨兵n填充，不能指向真实节点。
- LS行：相同E0邻接成员按原坐标FP64距离、节点ID排序，选前20并在右侧填充。长度排序决定原生提前break，先验分数不能替代距离。
- 备用行：来自该先验后续排名及少量均匀抽样；固定总槽位64，优先最多48个后续先验成员，再用16个均匀成员，仍不足则保留空槽。排除主行已有成员，保留先验次序和独立准备seed。Hard/Escape共享该资料及实际内存容量。

小规模测试按现有normalized_settings缩小行宽；正文实验保持16/64/20。备用采样只依赖点集身份、准备seed、节点ID，采用固定版本随机流；不消费ACO构造随机数。

## 完整Engine约束

Hard每次抽样前检查重定位真正新增的全部边；LS检查2-opt两条新边。哨兵在visited、距离或信息素读取前屏蔽。备用和全局最近未访问回退继续做同一合法性过滤，全部耗尽后停止该蚂蚁构造；完成的tour仍计一个search-tour FE。参考、档案、epoch和重启完全沿用共同控制底座，所有Hard tour必须在E0内。

GPU按colony上传完整CSR；实际邻接数可变，预分配容量固定、未使用部分不可进入查询范围。普通无约束路径不分配图缓冲。图身份和枚举行身份属于实例注册，注册后不可在同一key下变更。主搜索继续采用FE，无墙钟截止。外部LKH/图匹配准备与Engine内部准备资源分列，不能把只重做Engine准备称为包含LKH的完整端到端费用。

## Escape仍需完成的具体工作

真实32开发实例现已通过完整Hard验收，但当前备用有效成员数alpha每行64、POPMUSIC每行16；固定数组容量不代表有效访问量相同。正式四条件协议须在不读取成绩的前提下匹配两先验实际备用访问量，并记录尾部不足的处理。主/LS行在本次点集因最大度数≤16而实际槽总数相同，不把这一观察推广为任意图均相同。

固定1/16机会、替换1/4转移槽位的开发值保持不变。实现前须冻结每只蚂蚁的例外边容量、重定位所需边的原子预留、受影响端点的LS例外来源、溢出次序和跨批失效。LS例外通过替换已有槽位进入距离排序视图，不能追加第二套等宽检查。

父tour、epoch及档案可能来自不同LS例外视图。必须随参考传递受影响节点元数据，在例外失效、恢复普通槽位时重新激活这些节点；仅激活当前新扰动端点不够。旧图外tour边可以随合法参考保留，但不能因曾经出现过而永久进入新增边白名单。该部分未实现前不开放Escape生产开关，不将Hard通过解释为E3完整方法完成。

# 研究范围、关键分析与决策账本

## 1. 科学目标

v4 的研究对象是固定 FACO＋checklist LS 上的结构控制，而非新 ACO 转移公式或新 LS。保留四条证据链：E1 检验 LS 后反馈的样本外价值；E2 检验局部控制与重启的贡献和交互；E3 检验高质量候选是否能替代有限出口；E4 检验冻结规则的规模与结构迁移。CUDA 使实验可执行，性能剖析支持可信计时，不另立 RQ。

真正有区分度的比较是 **相同底座上重新训练的对照**。GP 超过作者 CPU 程序可能来自固定扩展、硬件或实现，不能单独支持反馈、协同或泛化主张。同样，完整方法最好并不自动说明 E2 的交互为正。

## 2. 已明确的设计

- 语义锚点为 Adaptive-Tuning 的 `run_mfaco`，不是默认入口 `faco_apt`，也不是另一个库的同名 FACO。
- 一个 colony 每批只选一次 `(restart, region, MNE)`；每只 ant 独立随机，批次内源 tour 和信息素只读。
- 单树、七函数、十二特征；最多 32 动作。GP 不调用 LS、不产生边权矩阵、不读最优标签。
- Python＋DEAP 只在离线演化和调度层；完整在线运行由 C++17/CUDA 负责，pybind11 粗粒度调用。
- 标准等精度 GP；无代理模型、多保真、强化学习或测试集选程序。

## 3. 开工时发现的实质缺口

| 缺口 | 后果 | 处理与验收 |
|---|---|---|
| 旧数据 README 排除 1K 训练 | 直接照抄会偏离 v4 | 用户授权全部可用；另建本研究 manifest，不改外部旧协议 |
| TSPLIB `.txt` 已归一化且无距离元数据 | 套官方最优值会得到错误 gap | 找回原 `.tsp`、原目标和标签映射；未匹配前隔离于正式 E4 |
| 文件名含 concorde/LKH，行仅给 tour | 可验证路线，不能从名字推出精确最优性 | 记录用户提供标签和证明来源两个字段，未证实者报告 reference gap |
| v4 的区域、档案、特征有建议定义 | 实现者可不经意改变方法 | 下表固定开发候选；只用 500/1K 开发数据比较，正式实验前签名冻结 |
| wall-clock 截止与 GPU 异步 | 迟到改进可能污染 fitness | 建立提交时间和截止验收，再训练 |
| 原生 MNE 与改边数不同 | 机制分析会错把阈值当真实扰动 | 分别记录构造步数、MNE、非恒等重定位和 LS 前后新边 |
| 最初没有实现或环境证据 | 不能从设计直接推断 GPU 加速 | G0–G3 先建立事实，再排正式计算 |

## 4. 开发候选定义（未正式冻结）

| 项目 | 首版可执行候选 | 冻结依据 |
|---|---|---|
| 动作 ID | `16*b + 4*j + k_index`，`j=0..3`，`k=(2,4,8,16)` | IR 与 mask 交叉测试 |
| 分数平局 | 先求合法全局最大分数，再在绝对差 ≤1e-6 的动作中取最小 ID | 避免成对近似比较的非传递性；报告平局率 |
| 区域 | 每参考解每批一次生成；两个随机起点的 16 节点连续片段、一个候选邻域、一个不放回分散集合 | 区域内去重，按固定候选/随机流补齐；不足 16 取 n，区域间允许重合 |
| 档案 | 容量 4，质量带 2%；保留 GB，按成本后规范化无向 tour hash 排序选其余不同解 | 替代参考按采样差异最大、成本更低、hash 更小排序；判不同用完整边集 |
| `e_R` | 节点两条 tour 边的均长／固定近邻距离均值；`clip((ratio-1)/3,0,1)` 后区域均值 | 保护尺度 `1e-12 × max(实例坐标跨度,1)`，只在开发集检查饱和率 |
| `v_R` | 区域当前两侧边在实际档案成员中缺失的比例 | 档案只有自身时为 0；不虚构四个成员 |
| `p_R` | `(tau-tau_min)/(tau_max-tau_min)` 裁剪后区域均值 | 上下界相等时定为 1；图外查询使用 default |
| 反馈 | `q,c` 用 EMA 1/16，首批从零更新，重启清零；`s=min(stall/32,1)` 不清零 | 记录有效样本数；空批不伪造零反馈 |
| LS 限额 | 保留原生接受上限，另设相同 move-evaluation 限额和截止 | 数值经统一底座 500/1K pilot 确定，不能用测试结果选 |

这些不是新科学假设，也不称作调优结果。任何改变记录到配置和报告；冻结后改变需新实验版本，不能覆盖旧结果。

## 5. 失败时的分支

E1 无收益：先排查终端是否恒定、动作差异是否相消、mask 是否有效、计时是否偏置，再接受无反馈增益。E2 交互非正：报告可加或替代关系。E3 Hard 已足够：报告先验的适用条件。E4 迁移失败：保留失败实例和规模组，后续训练属于新版本，不能回填当前零样本结果。

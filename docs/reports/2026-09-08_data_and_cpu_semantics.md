# 主池划分与 CPU FACO 操作语义核验

日期：2026-09-08。机器可读证据见 [data_cpu_results.json](data_cpu_results.json)。本阶段完成500/1K主池身份登记和 CPU 操作级对照；没有运行正式测试集上的求解器，没有 E1–E4 质量结论，也没有完整 CUDA FACO 或训练闭环。

## 数据身份

16个主池文件的128,416条记录全部通过坐标、tour 排列、闭环与连续目标成本检查；整文件字节数、行数、SHA-256与原清单一致。共128,416个精确点集组，未发现相同坐标点集或节点置换重复。旋转、缩放、子采样的父来源元数据缺失，仍须保留亲缘关系检测的局限。

| 规模 | 开发 | 训练 | 验证 | 原同分布测试 |
|---|---:|---:|---:|---:|
| 500 | 128 | 63,744 | 256 | 128 |
| 1K | 128 | 63,648 | 256 | 128 |

验证池分别从训练来源补入128/224个组，已经用于原生 smoke 的两个实例固定留在开发池。排名只使用预登记 seed 与点集 hash，公开的 [split manifest](../../provenance/splits.v1.json) 含文件指纹、非训练池实例 ID 及各池成员 SHA-256，不含标签值或 tour。

核验脚本在禁止读取 `labels` 表的内存副本上重放所有分组，结果与数据库和公开 manifest 一致。所有开发/验证/测试记录及每规模128条训练记录，共1,280条，额外通过字节偏移读取、行 hash、点集和标签对象核对。测试访问属于格式/标签审计，性能仍未揭盲。标签保留用户给定最优声明，没有根据文件名补写最优性证书。

## CPU 语义对照

编译器 GCC 15，C++17，Release；测试直接编译只读 Adaptive-Tuning 源码，通过真正的 Route、选点及 CandListPheromone 对象对照移植层。原始来源文件指纹复核未变。断言不依赖 Debug 模式，Release 也会在差异时返回失败。

| 检查 | 实际覆盖与结果 |
|---|---|
| relocate | n=3..7全部排列、全部不同端点，共236,004次；tour、positions、成本一致；三条移除/新增边可重建结果 |
| reverse | n=3..7全部排列及端点，共276,318次；保留原生环绕边界导致的数组方向 |
| 构造＋checklist 2-opt | n=8/17/100/500/1000，连续/舍入整数/重复坐标三类，共480组；3,470次构造状态转换全部一致 |
| MNE | 计数、checklist及停止条件与原生一致；确实观察到 MNE 不等于最终改边数，后续构造可撤销先前改边 |
| LS 顺序与重新激活 | 3,790,981次 move evaluations、308,419次端点重新入队；输出 tour 与 checklist 完全一致 |
| 有限 LS 评价上限 | 1/7/127三种上限共1,440组，以及480组零上限；不越限、保持排列与成本一致 |
| 正权重选点与回退 | 12,800次与原生相同随机流逐次比较；主候选、备用及全局回退均覆盖 |
| 零/极小权重概率 | 分层均匀网格共30,000次，正权重、全零回退和1e-300量级权重频数均匹配；包含0及接近1的端点 |
| 信息素 | 对称/非对称有向行共256次蒸发强化序列；36组上下界公式；default重置及产品缓存重算 |
| 成本完整重算 | 最大绝对误差1.8047785488306545e-12；不将此界外推到完整长时间求解 |

首轮对照捕获并修正了移植中“直接反转较短补片段”的简化：原生 `first==0` 时的环绕计算会产生不同数组方向。最终实现保留原生行为。除此之外，原生仅剩一个零权重候选时可返回当前已访问节点的问题得到直接确认，共同底座明确改为在合法主候选中均匀回退。

有限评价上限及完整 stored/default 重置也是共同底座的声明适配，详见 [语义协议](../planning/03_faco_semantics_and_baselines.md)。初始化 EdgeGuard 仍为独立适配版本，本次 checklist 2-opt 对照没有修改源函数。

## 验证与限制

Python 全套31项测试通过；C++ Release CTest通过。另一独立 `RelWithDebInfo` 构建启用 AddressSanitizer、UndefinedBehaviorSanitizer、泄漏检测和首错终止，运行相同操作检查通过，机器可读结果与Release完全一致。复现命令见 [reproduce.md](reproduce.md)。历史启动阶段的CPU27/GPU29项测试及评分结果保持原报告口径，不改写成当前 FACO 实现的 GPU 验收。

当前 CPU 对象是语义参考，不是完整 wall-clock 求解器；还没有 CUDA 构造/LS、Hard/Escape合法性执行、完整重启事务、12个特征、持久Engine与真实GP评价。G1的已覆盖操作具备继续移植的证据，G2–G4仍需按各自门槛完成。下一项工作是以本次 CPU oracle 为依据建立无GP CUDA操作对照，之后接入状态与截止协议。

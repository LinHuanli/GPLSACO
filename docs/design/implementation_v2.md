# 当前实现与参数依据

本项目保留节点重定位的 FACO 底座，用 GP 选择局部扰动与重启动作。原始 2022 FACO 另设独立比较组，两者的构造方式和初始化不同，不把 GPU 版本标成原始算法的逐步等价复现。

GP 训练与候选验证支持整个 128 个体种群在 GPU 展开，共享面板几何数据，保留独立搜索状态和完整 FE。布局、内存和结果恢复见 [种群 GPU 设计](population_gpu_v2.md)。

| 参数 | v2 设置 | 依据 |
|---|---|---|
| 蚂蚁数 | `64 × ceil(sqrt(n)/16)` | [2022 论文](https://arxiv.org/html/2203.02228) §5.6；显式覆盖原始源码的 `lround` 默认值 |
| 正式验证和测试迭代 | 5000 | 2022 论文 §5.6 |
| 当前TSP500训练迭代 | 1000；快速验证/监控同预算 | TSP500开发曲线的改善保留和排序稳定性均通过门槛；最终验证/测试仍5000 |
| beta、信息素保留率 | 1、0.5 | 2022 论文表 1、§5.6 |
| 主候选、备用候选宽度 | 16、64 | 2022 论文表 1 |
| LS 候选宽度、p_best、全局最好解作源概率 | 20、0.1、0.01 | 2022 作者源码 `progargs.h` |
| 固定对照 MNE | 8 | 2022 论文 §5.6 |
| GPU 底座初始化 | 节点 0 最近邻路线 + checklist 2-opt | 现有实现选择；原始 FACO 使用多初解、2-opt 和 3-opt，须分别报告 |
| 每蚂蚁 LS 检查次数上限 | 100000 | 现有工程设置；不是论文参数，GP 与同底座对照保持一致 |

TSP100、500、1000、10000 分别使用 64、128、128、448 只蚂蚁。FE 定义为搜索中构造的完整蚂蚁路线：每实例每个求解 seed 的 `FE = 蚂蚁数 × 迭代数`。初始化和 LS 候选检查另记成本，不能混成 FE。算法不设墙钟截止时间。

当前 GP 外层使用种群 128、50 个完整评价代、3 次独立进化，仅训练和选模TSP500，每代16实例×1个ACO seed。初始化深度 1–3，最大深度 5、最多 63 节点；锦标赛规模 4、精英 4，交叉概率 0.8、子树变异概率 0.2，使用 DEAP `varAnd`。这些是已有开发方案的工程选择，没有做超参数搜索，也不声称是最优参数。每代包括精英和重复树在内的全部个体都重新评价。两级验证和冻结后TSP1000迁移规则见[当前协议](../experiments/round_three_seed_v2.md)。

文件、源代码、二进制、坐标、程序身份、检查点和实验记录不计算完整性摘要。程序使用代号与个体号，任务使用实际评价位置编号，结果按追加日志保存；代际边界和正常停止写完整快照。恢复读取快照后的完整日志记录，不重复已完成的求解和评分。保留输入形状检查、CUDA 错误处理及外部最终路线评分。算法内部的路线指纹仍用于档案去重，并保留碰撞后的精确比较。

GPU 优化以 [MTGP_ACO 本地实现](../../../../MTGP_ACO/docs/performance/cuda_fused_architecture_20260724.md) 为参考：数据驻留、warp 协作、距离复用和减少主机交互。保留当前 FACO 的 checklist 顺序、最大增益选择、平局规则及候选约束；不引入其 first-improvement 或额外容差。数值近似只有通过开发集质量和速度门槛后才允许冻结。

科学问题仍以 [研究方案 v4](GP_ACO_TSP_Research_Proposal_v4.md) 为范围；其旧时间预算被当前次数协议覆盖。旧实现和旧参数的说明归入 [v1 历史资料](../archive/v1/README.md)。

生产 CUDA 主路径在 n≤1500 时用一个 warp 处理一只蚂蚁，一个 block 包含四只。tour、位置和暂存使用 uint16 共享内存；主机仍使用原公开 uint32 路线接口。较大实例和图约束路径保留兼容实现。

每轮父代先逐边并行算距离，再按原始 i 顺序累加一次，各蚂蚁复用该结果。LS 候选距离按固定候选表复用，checklist 的直接索引成员标记保持 FIFO 和重新入队次序。档案并行比较保留候选平局次序，指纹碰撞仍精确比较。GP 表达式评分在已测面板中不是主要耗时，因此当前无需增加每个表达式单独生成和编译 CUDA 的成本。

原始 FACO 的连续适配明确命名为 `faco_2022_continuous_identity_guard`：原始 double 距离矩阵、连续 NN 排序、作者 NN-list 初始化分支，加上 3-opt 恒等边集合排除。原始 KD-tree 内部会对距离取整，连续适配关闭它；原始 TSPLIB 复现仍使用未适配的距离与候选路径。两种构建和产物目录分开。

当前规模 n≤1500 缓存完整距离表以避免 LS 重复开方：32 colonies 在 n=1000 时额外使用约 244.1 MiB。缓存按相同 exact/FP32 距离规则计算一次，没有坐标量化。更大规模不分配该表，保留按需计算距离的路径。当前主规模的速度与显存会一并实测报告。

局部搜索修订 `checklist_2opt_identity_zero_v2`：相邻边的 2-opt 无向边集合不变，增益直接设为零，排除浮点假改善重复计入 accepted_moves。该修订同步 CPU/GPU 与 2022 连续距离适配（revision 2），会改变轨迹；所有正式 v2 对照与训练均采用修订后实现。原始 TSPLIB 整数目标的 180 次结果保持原作者实现，不受影响。

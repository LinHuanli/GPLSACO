# E2：局部扰动与重启的 2×2 析因

当前底座、数值后端和预算服从 [v2 协议](protocol_v2.md)。动作限制、独立重训、逐批行为记录已经实现并通过工程测试；正式四格实验尚未完成。

| 变体 | 学习局部扰动 | 学习重启 | 未学习部分 |
|---|---|---|---|
| M00 | 否 | 否 | 开发/验证选定的区域、MNE 与重启规则 |
| M10 | 是 | 否 | 重启由 M00 决定 |
| M01 | 否 | 是 | 区域/MNE 由 M00 决定 |
| M11 | 是 | 是 | Full 联合评分 |

M10/M01 各按同样五个进化 seed、128×50 完整重训，共享预先登记的 50 代面板；不能对已经训练好的 M11 临时屏蔽输出代替重训。没有替代 reference 时，各变体均不可重启，需要记录实际重启机会数。

主要终点使用 5000 迭代损失。实例内先平均求解 seed，再计算 `Syn = L10 + L01 − L00 − L11`，做配对 bootstrap；进化重复分别报告。正值表示当前损失尺度上的超可加收益。另报两个基本效应及 M11 相对最佳单因素的差。

机制指标包括每 FE 重启数、合法机会、重启后 MNE、真正新边、LS 返回率和后续改善。正式执行需先完成 M00 和 Full 的选择。入口为 `scripts/train_gp.py --condition M10/M01 --factorial-policy ...`；参数文件需包含已经选择的 M00 规则。

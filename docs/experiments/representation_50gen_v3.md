## 1. 训练设置与依据

| 参数 | 数值 | 依据 |

| fitness | 16条终局路线平均reference gap% | 求解器返回后，外部坐标距离和math.fsum评分；无中间轨迹分数 |
| 初始化 | 高度2/3/4与full/grow分层 | 保留修复后的v3初始化，不把提前终止的grow叶子记为目标高度 |

蚂蚁数使用FACO2022主实验公式 `64×ceil(sqrt(n)/16)`，TSP500和TSP1000均为128。beta=1、rho=0.5、主/备用候选16/64、LS候选20、p_best=0.1、epoch source概率0.01。论文依据及作者适配差异沿用[实现说明](../design/implementation_v2.md)与[预实验协议](representation_pilot_v3.md)。训练H1000复用已有开发集标定，最终验证和测试H5000。GP允许MNE=2/4/8/16，是本研究的控制动作。

底层使用exact：FP64距离、搜索成本与增益，GP运算仍采用既有FP32有界grammar。运算符为ADD、SUB、MUL、MIN、MAX、ABS、AQ；不改变AQ舍入、截断及1e-6评分平局规则。保持原初始化、FIFO checklist LS、最大增益选择及随机数域。

每个体2,048,000 FE，每代262,144,000 FE，每次50代13,107,200,000 FE，六次合计**78,643,200,000 FE**。重复表达式和精英也完成本代全部评价。初始化、LS工作量、baseline、监控、验证、测试另记，不混入训练FE。

## 2. 表示、输入和输出

一个individual只有一个外部fitness。单树为32个合法候选完整动作评分；三树在同一动作前状态依次输出restart的2项、region的4项、MNE的4项条件分数，最终提交一次动作。动作编号为`16×restart+4×region+level`；level=0/1/2/3映射到MNE=2/4/8/16。

restart树不能读取未选择的region/MNE特征；region树不能读取未选择的MNE特征。完整角色限制与12个输入定义沿用[预实验协议](representation_pilot_v3.md)。`ref_gap`是算法内部来源路线相对当前最好路线的差，不是参考最优解标签。

64个行为情境复用首训练面板采样；繁殖调用同一CUDA评分器，避免CPU/GPU近并列差异。反馈干预只是解释诊断，不参与fitness、选择或强制复杂度。表达式浅或反馈作用弱会如实报告。

## 4. 对照、测试与统计

四类对照为原始FACO2022连续适配、GPU FACO MNE8均匀起点且不重启、固定MNE16/region0且不重启、GPU MNE16均匀起点且不重启。原生对照保持8线程、24条初始路线，每主机最多一个任务。GPU底座与原生FACO并非逐步等价，分别回答相对作者方法及相对共同GPU底座的提升。

训练前补齐50训练面板、监控和两级验证的对照；同方法、实例、seed、H及既有参数声明的结果可复用。四个测试对照在冻结后运行，六个GP方法共享同一份baseline结果。独立控制器分别执行与计时，报告单方法速度不使用多控制器并行摊销。

测试ACO seeds为17、29、41、53、67、79、97、109、127、149。先平均每实例的ACO seeds，再汇总实例和3个GP seeds；单列每次进化成绩，不按测试效果删选。正改善百分点定义为`对照gap−GP gap`；相对路线改善为`100×(对照cost−GP cost)/对照cost`。

报告实例胜平负以及10000次GP seed、实例、实例内ACO seed分层配对bootstrap的95%区间，统计seed91001。TSP500预登记九项比较：两种表示分别对四基线，加单树对三树；实例均值配对Wilcoxon并对九项统一Holm校正。TSP1000只报告描述性比较和区间，不追加主检验。

解释回放采样迭代1、100、500、1000、2500、5000。保存完整12×32输入、mask及实际分数；单树展示32项，三树展示真实2/4/4条件评分。采样关闭时没有这些返回开销。

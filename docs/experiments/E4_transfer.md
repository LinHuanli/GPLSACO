# E4：冻结规则的规模与结构迁移

正式迁移测试尚未运行。E1–E3 完成验证和方法选择后，记录程序普通编号、表达式、常数、动作设置、候选、距离、数值后端、LS 和重启设置，形成命名的冻结包。实验管理不计算哈希。

规模轴使用同分布 TSP100/500/1000/10000；蚂蚁数分别 64/128/128/448，正式 5000 迭代，每实例求解 seed 见 [v2 协议](protocol_v2.md)。单独报告每个规模，不能让较小规模掩盖 10K 的失败。跨规模表现不能用于回头修改程序或训练预算。

结构轴恢复 TSPLIB 的原始目标：原始坐标 EUC_2D、CEIL_2D、ATT、GEO 和显式对称距离格式。解析器和外部原始距离评分已通过 CPU 测试；原始 FACO 2022 已有六个 TSPLIB 实例各 30 次的复现数据。

当前 GP GPU 输入仍是连续欧氏距离，不能将归一化坐标的连续结果写成 TSPLIB 原始整数距离结果。GPU 原始距离分支、归一化文件到原问题的完整对应和正式迁移评价仍需完成。支持范围应逐实例说明，无标签或暂不支持的实例保留状态，不偷偷换目标。

交付应包含跨规模 gap/成本、TSPLIB 逐实例表、各进化 seed 的表现和失败率。1K 有效而 10K 失败表示外推不足；在 10K 继续训练应另立实验版本。

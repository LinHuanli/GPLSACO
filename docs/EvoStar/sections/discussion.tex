\section{讨论与结论}
当前实验支持三点判断。第一，GP能在共享GPU求解器上学到可执行、规模较小的结构控制程序，并超过MNE8静态对照。第二，强度16静态对照解释了相当部分收益；在TSP500上尚未获得GP优于这些强对照的可靠证据，在TSP1000上固定区域强度策略反而更好。第三，条件三树保留了结构和行为多样性，却付出了更高训练成本，没有显示稳定的质量优势。

解释这些结果需保留边界。两种表示共享总节点上限，但搜索空间、特征可见性和繁殖方式仍不相同，比较反映的是完整表示方案而非单一树数量因素。3个进化种子不足以精确刻画运行间变异；终点适应度区分个体，却不提供逐动作回报。停滞特征在连续32次未改善后饱和，且重启不清零该全局计数，可能降低后期状态分辨率。短训练与长测试预算、有限回放覆盖，以及数据生成元信息不完整，也限制了进一步推论。

后续工作应先在开发集固定MNE16，并分别移除反馈、参考路径切换或区域选择，以完整求解结果估计各部分贡献；再检查停滞缩放、重启冷却和预算条件化是否改善迁移。上述实验尚未完成，现有E1--E4设计不能作为其结果。

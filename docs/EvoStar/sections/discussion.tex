\section{Conclusion}
本文将FACO的参考路径切换、起点区域和扰动强度表述为GP可学习的控制决策，并比较single-tree联合评分与multi-tree条件选择。TSP500实验表明，两种表示均学到优于固定MNE=8配置的规则。较强的MNE=16静态对照取得接近的质量，TSP1000上的区域静态策略进一步超过两种GP。规则分析与采样决策一致显示对MNE=16的偏好，反馈对控制的影响主要体现为区域和重启动作。Multi-tree在当前预算下增加训练成本，尚未取得明确质量收益。

这些结果将下一步问题集中到动态控制的增量价值。现有评价采用完整求解后的scalar fitness，三个控制角色共同承担credit assignment；未来应在开发集固定MNE=16，分别控制反馈、区域选择及参考路径切换，测量各部分对终点质量的影响。同时检查停滞特征的分辨率、重启频率及训练与部署预算的差异。现有结论来自三个GP seed、一个训练规模和一个迁移规模，更广泛的泛化表现仍需独立实验评价。

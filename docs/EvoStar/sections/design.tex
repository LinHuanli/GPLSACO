\section{Experimental Design}
\subsection{Research Questions and Baselines}
实验回答三个问题：（RQ1）GP控制是否改善FACO的求解质量？（RQ2）GP学到了什么控制行为，single-tree与multi-tree有何差异？（RQ3）所学策略能否迁移至更大实例，其计算成本如何？RQ1使用冻结测试及静态对照；RQ2结合训练与validation曲线、选中规则和决策回放；RQ3考察TSP1000迁移及搜索工作量。

比较方法包括\JS{}、\CT{}及以下四种baseline。两种GP各运行3个独立GP seed（1103、2207、3313），所有运行从头初始化。
\begin{itemize}
 \item \FACO{}：2022原生FACO的连续距离适配版，保留24条初始化路径及原生初始化local search，用于评价整体求解质量。
 \item \Ueight{}：共享GPU底座，固定MNE=8，从全体节点均匀选择起点，不重启，作为默认强度对照。
 \item \Usixteen{}：将\Ueight{}的MNE改为16，检验较大扰动强度的表现。
 \item \Rsixteen{}：固定MNE=16，从每次迭代随机生成的区域0选择起点，不重启，检验简单区域策略的表现。
\end{itemize}
三个GPU baseline与GP共享路径构造、local search及数值后端。\FACO{}使用连续FP64距离，并对依赖整数距离的近邻实现和恒等移动处理作相应适配；详细改动见补充材料。另有六个TSPLIB实例、各30个seed的原始整数距离复现\cite{reinelt1991}，单独作为原生FACO与参数核查的证据。

\subsection{Data and Evaluation Protocol}
训练仅使用500节点欧氏TSP，1000节点实例用于冻结后的规模迁移。数据清单将该合成实例族记为uniform；现存元数据没有完整记录生成器及父实例关系。数据提供的参考路径用于式\eqref{eq:fitness}中的外部评分，路径长度按连续欧氏距离计算。下文所有合成实例的gap均指reference gap，越低越好。

训练包含50个评价代，每代16个实例、1个ACO seed，所有individual使用相同面板。面板随代变化，合计覆盖794个不同训练实例。固定开发面板每5代监控一次冠军。训练结束后，用quick validation重评历代冠军及末代种群，再对前4名执行full validation，选出本次运行的控制器。六个控制器全部冻结后，才在两个规模的测试集上评价。表\ref{tab:protocol}给出各阶段预算。

训练采用较短ACO预算的依据来自先前开发标定：24个固定或规则控制器在32个开发实例、5个ACO seed上比较$H\in\{100,250,500,1000,2500,5000\}$。选择条件为保留至少95\%的相对初始化改善，且与H5000的控制器排名Spearman相关至少0.9。H1000是首个达标候选；TSP500的改善保留率为98.73\%，排名相关为0.9383。该标定降低训练成本，GP的最终选模仍使用H5000评价。

\subsection{Performance Measures and Statistical Analysis}
质量以平均reference gap报告。先平均ACO seed，再平均实例及GP seed；同时报告相对baseline的改善$\Delta=\gap_{\rm baseline}-\gap_{\rm GP}$，单位为百分点，正值表示GP更好。计算成本分别使用GPU任务时间、构造步数和local-search移动评价数。

TSP500的主检验以128个测试实例为配对单位，每个实例先平均10个ACO seed和3个GP seed，采用双侧Wilcoxon signed-rank test\cite{wilcoxon1945}。两种GP各对四个baseline，加上GP之间的比较，共9项检验统一采用Holm校正\cite{holm1979}。95\%区间沿用10\,000次分层配对bootstrap，重采样GP seed、实例及实例内ACO seed。TSP1000区间用于描述迁移效果。三个GP seed限制了对进化随机性的估计精度，逐seed结果另列于补充材料。

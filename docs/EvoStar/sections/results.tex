改善参考差距的相对比例不等于路径缩短比例。例如，\JS{}相对\Ueight{}的差距均值下降约12.9\%，对应的逐样本平均路径长度改善仅约0.02165\%。相对\Rsixteen{}，路径长度改善约0.00392\%。因此，当前收益应按绝对百分点及区间解读，不能表述为路径缩短十几个百分点。

TSP1000上，\Rsixteen{}的平均差距0.22825\%低于\JS{}的0.25236\%和\CT{}的0.24563\%。相对该对照，两种GP的$\Delta$分别为$-0.02411$与$-0.01738$个百分点，描述性95\%区间分别为$[-0.03655,-0.01053]$与$[-0.03252,-0.00377]$。这表明在本次测试族中，TSP500学到的策略未能超过固定区域强度策略。由于只考察一个训练规模和一个迁移规模，该结果不支持对其他实例分布作进一步推断。

按10代窗口平均，\JS{}快速验证差距从前10代的0.24250\%降至后10代的0.23166\%，\CT{}从0.24669\%降至0.22815\%，改善幅度有限且并不单调。6次运行中有5次的历史最佳快速验证冠军出现在第10代之后，但后期候选数量更多，不能据此单独证明延长训练的净收益。

完整验证选中的6个个体均不是末代训练冠军，且仅2个是快速验证第一名。以\JS{}种子1103为例，快速验证第一名在完整验证中的差距为0.14551\%，而快速验证第四名达到0.12667\%，最终被选中。两个阶段同时改变了实例、ACO种子数和迭代预算，该反转无法归因于其中任一因素。它说明在当前噪声和预算差异下，直接部署末代训练冠军或快速验证第一名均缺少依据。

末代种群在全部运行中均有128个不同程序、100--115个不同的64情境动作向量，相同行为最多2个个体；个体最大树高的中位数为4--5。末代不同适应度值数量为104--121，最优适应度均无并列。新繁殖规则下未观察到整个种群退化为深度1的现象。该结果说明结构和观测行为仍有区分度，但不能把终点适应度称为密集的逐动作训练信号：每个个体仅获得完整求解后的平均标量，三树仍共同承担信用分配。

\subsection{进化程序的行为}
选中个体包含5--35个节点。最短个体是\JS{}种子3313的
\begin{equation}
 f=\AQ\!\left(m,\AQ(r,d)\right).
\end{equation}
其中$m$为\texttt{mne\_level}，$r$为\texttt{return\_rate}，$d$为\texttt{region\_dispersion}。在未触发数值并列的实数分析下，它随$m$增大而增大；当$r>0$时，较高的区域离散度减小内层解析商，使外层得分更高。它未显式读取重启标记，但不同参考路径产生的区域特征仍可改变完整动作排名。实际选择必须保留FP32和$10^{-6}$并列规则。

三个\CT{}的强度树分别可写为
\begin{align}
 f_k^{1103}&=\AQ(m,m),\\
 f_k^{2207}&=\AQ\bigl(\max(m,mp),\min(|w|,|p|)\bigr),\\
 f_k^{3313}&=m+(p+r),
\end{align}
其中$p$为进度、$w$为局部搜索工作量、$r$为回归率。在本输入域内，三式都偏好最大$m$，因此条件表示虽然保留强度决策接口，所得强度规则实质上趋于固定16。

这一点与有限回放一致：6个控制器在64个冻结训练情境上共384次决策，以及每个控制器每个规模12次真实决策回放，共144次，全部选择MNE16。真实回放来自每规模2个开发实例、种子17、迭代1、100、500、1000、2500、5000；它不是正式测试的完整动作轨迹。将停滞、回归率或工作量分别设为0或1后，没有观察到MNE变化，但部分区域及重启动作发生变化。表\ref{tab:feedback}给出固定训练情境上的置零结果。

正式测试保留的完整求解累计量显示，重启频率差异很大。TSP500中，\JS{}三个控制器每5000迭代平均重启0、402.8、492.8次；\CT{}分别为433.8、231.4、726.4次。后者种子3313的某次求解重启4798次。大量重启与缺少冷却机制相容，但未开展固定其他因素的完整求解消融，不能认定它造成了质量下降。采样动作、表达式分析与累计计数共同支持“反馈确实改变部分控制决策”，尚不支持“反馈改善最终求解质量”。

\subsection{计算成本与加速效果}
六次50代训练、选模及测试共2382个任务完成，无失败或重试，分布式完整流程约5.98小时。每次运行的训练GPU任务时间之和，\JS{}平均283.72分钟，\CT{}平均393.21分钟，后者增加38.6\%。两者监控加选模的GPU时间分别约为训练的11.3\%和10.7\%，验证未超过训练成本。多GPU重叠执行使这些累加时间不同于墙钟时间；训练墙钟范围分别为3.83--3.85和4.32--4.63小时。

同卡工程对比中，在10代预实验的初代／末代样本、$H=100$下，最近一轮布局优化使四组种群评价耗时降低10.7\%--14.4\%，保留路径输出与工作计数。正式测试中，GP的摊销GPU求解时间仍是\Ueight{}的约1.29--1.73倍，局部移动评价数为其约1.52--1.80倍。较高强度带来的额外搜索工作抵消了部分调度收益。\CT{}每步仅需10个评分而\JS{}最多32个，并不意味着端到端求解更快，因为控制决策改变了后续构造、局部搜索和重启的工作量。不同服务器的批处理吞吐不能当作孤立求解延迟，CPU原生对照也不用于直接宣称GPU加速倍数。
